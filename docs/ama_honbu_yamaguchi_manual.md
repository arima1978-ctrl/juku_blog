# あま本部校ブログ 毎朝の確認手順(山口先生用)

最終更新: 2026-07-28。動作確認済み(下書き作成・投稿者・カテゴリー・cron完走を本番で確認済み)。

## 毎朝やること(所要時間の目安: 3〜5分)

1. WordPress管理画面を開く
   `https://an-english.com/wp/wp-admin` にログイン
2. 下書き一覧を直接開く(ブックマーク推奨): 
   `https://an-english.com/wp/wp-admin/edit.php?post_status=draft&author=10`
   (山口先生名義・下書きのみに絞り込み済みのURLです。他の校舎の記事は表示されません)
3. 新しい下書きのタイトルと本文を読む
4. 内容を確認して、以下のどれかを選ぶ
   - **そのままでOK** → 「公開」ボタンを押す(すぐ載せたくない場合は「即時」の横で日時を指定して予約も可)
   - **少し直したい** → 本文を直接編集してから「公開」を押す
   - **今回は載せたくない** → 「ゴミ箱へ移動」

## 確認してほしいポイント(事実関係)

- 学校名・地域名が合っているか(実在する学校名か、あま本部校の対象エリアと合っているか)
- 日付・曜日・季節の記述に矛盾がないか
- イベント情報(体験授業・説明会など)の日時・内容が最新の実情と合っているか
- 生徒の実績・エピソードとして書かれている内容に、事実と違う点がないか

## 気にしなくていいこと

- SEO関連(メタディスクリプション・タグ・カテゴリー・アイキャッチ画像の設定)は
  システム側で自動設定済みです。空欄に見えても触らなくて大丈夫です。
- 文章の型(結論を先に書く・Q&A形式を入れる等)は執筆システム側のルールに沿って
  作られているので、読みやすさの微調整以上に構成を大きく変える必要はありません。

## 通知について

現在、下書きが作成されてもメール等の通知は届きません。毎朝上記URLを開いて確認する運用です
(下書きが数日分たまっても、一覧で見やすいのでまとめて確認して問題ありません)。

## 困ったとき

- 内容に事実誤認があるが直し方が分からない → そのまま「ゴミ箱」へ移動して、有馬まで一言連絡
- WordPressにログインできない・下書きが見当たらない → 有馬まで連絡
